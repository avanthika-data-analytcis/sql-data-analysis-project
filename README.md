# SQL Medical Data History Analysis Project

## Project Overview

This project demonstrates SQL techniques used for data analysis
and solving business-related questions.

## Database

MySQL

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- CASE
- Aggregate Functions
- Subqueries
- INNER JOIN
- LEFT JOIN
- Window Functions
- RANK()
- DENSE_RANK()

## Analysis Performed

- Employee salary analysis
- Department-wise salary analysis
- Average salary analysis
- Second highest salary
- Top salaries by department
- Employee and department analysis

## Skills Demonstrated

SQL querying, data filtering, aggregation,
joins, subqueries, and window functions.
